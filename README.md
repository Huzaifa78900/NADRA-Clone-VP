# NADRA Citizen Management System v2 (.NET 8 WinForms)
Requirements: Windows 10/11, .NET 8 SDK, VS Code + "C# Dev Kit".

    cd NadraApp
    dotnet restore
    dotnet run

nadra.db is created automatically with sample data. Errors are logged to error.log.
Shortcuts: Ctrl+N new, Ctrl+S save, Ctrl+F search, F5 refresh, Ctrl+1..6 switch tabs.
